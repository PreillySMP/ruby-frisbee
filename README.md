# Ruby's Frisbee

A frisbee-catching game starring **Ruby**, a black-and-tan German Shepherd who loves frisbee.

You play as Ruby — run, jump, and catch frisbees before they hit the ground!

## Play on your phone (no install)

1. Go to **Settings → Pages** in this repo
2. Source: branch **`main`** (or `master`), folder **`/docs`**
3. Open **https://preillysmp.github.io/ruby-frisbee/**

See [docs/README.md](docs/README.md) for details.

## Controls

| Phone | Desktop |
|-------|---------|
| Hold ← → to move | Arrow keys or A / D |
| Tap **Jump** | Space or W |

## What's in this repo

| Folder | Description |
|--------|-------------|
| `docs/` | Browser game (HTML5) — play instantly via GitHub Pages |
| `RubyFrisbee/` | Full Unity 6 project for desktop/mobile builds |

## Unity version

Open `RubyFrisbee/` in Unity 6, then run **Ruby Frisbee → Setup Game Scene**. See [RubyFrisbee/README.md](RubyFrisbee/README.md).
