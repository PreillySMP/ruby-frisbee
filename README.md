# Ruby's Frisbee

A frisbee-catching game starring **Ruby**, a black-and-tan German Shepherd.

**Play in your browser:** https://preillysmp.github.io/ruby-frisbee/

## Controls

| Phone | Desktop |
|-------|---------|
| Hold ← → to move | Arrow keys or A / D |
| Tap **Jump** | Space or W |

## Repo layout

| Folder | Description |
|--------|-------------|
| `docs/` | Browser game (GitHub Pages) |
| `RubyFrisbee/` | Unity 6 project |

## Unity version

Open `RubyFrisbee/` in Unity 6 → **Ruby Frisbee → Setup Game Scene**
