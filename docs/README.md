# Ruby's Frisbee — Quick Browser Version

Play instantly in your phone browser via GitHub Pages.

## Enable GitHub Pages

1. Open **github.com/PreillySMP/ruby-frisbee**
2. **Settings → Pages**
3. **Source:** Deploy from a branch
4. **Branch:** `main` (or `master`) → folder **`/docs`**
5. Save and wait 1–2 minutes

## Play

**https://preillysmp.github.io/ruby-frisbee/**

### Add to home screen

- **iPhone:** Safari → Share → Add to Home Screen
- **Android:** Chrome → Add to Home screen

## Controls

| Phone | Desktop |
|-------|---------|
| Hold ← → to move | Arrow keys or A / D |
| Tap **Jump** | Space or W |

## Local testing

```bash
cd docs && python3 -m http.server 8080
```

Visit `http://localhost:8080`
